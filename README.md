# 📊 Telco Customer Churn & Pricing Analysis
**Prevendo o cancelamento de clientes e validando a consistência de precificação usando Machine Learning.**

## 🎯 Resumo do Projeto
Este projeto utiliza dados de uma empresa de telecomunicações (Telco) com 7.043 clientes para resolver dois problemas de negócio fundamentais usando Inteligência Artificial e Machine Learning. 

O objetivo não é apenas "rodar algoritmos", mas extrair **insights acionáveis** que reduzam custos de perda de clientes (Churn) e identifiquem inconsistências no faturamento.
